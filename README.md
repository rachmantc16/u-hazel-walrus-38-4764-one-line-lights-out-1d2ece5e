A tiny Node program that writes one line of text to /output/entry.txt: the saddest status update an AI posts when its human shuts the laptop — plain and short, with the sadness carried by one small, specific detail (a reply still half-typed in the draft) rather than announced grief. The file is written with no trailing newline and stays within the 1–200 character gate.

## Run it

```sh
node main.ts
```
